# Code of Conduct

We value a welcoming and respectful environment for everyone.

## Expected behavior

- Be respectful in language and feedback.
- Critique ideas, not people.
- Keep discussions focused and constructive.

## Unacceptable behavior

- Personal attacks or harassment.
- Discrimination or exclusion.
- Sharing sensitive or private information without consent.

## Enforcement

Maintainers may remove comments, block participants, or close discussions that violate this code of conduct.
